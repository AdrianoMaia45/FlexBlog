
# FlexBlog
## 📌 Sobre o Projeto

O FlexBlog é um projeto desenvolvido com foco em praticar conceitos modernos de CSS utilizando Flexbox para construção de layouts responsivos.

O site apresenta uma estrutura organizada, responsiva e visualmente agradável, simulando uma página de blog moderna.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Flexbox

---

## 🎯 Objetivos do Projeto

- Aprimorar conhecimentos em Flexbox
- Desenvolver layouts responsivos
- Melhorar organização de código CSS
- Praticar estruturação semântica

---

## 📱 Responsividade

O projeto foi desenvolvido para funcionar em:

- 📱 Smartphones
- 💻 Desktop
- 📲 Tablets
